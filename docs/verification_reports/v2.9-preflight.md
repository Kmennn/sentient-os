## 3. Known Issues

- **Global Path Optimization**: Planner optimizes each leg individually, not the full chain globally.
- **Dynamic Obstacles**: Planner assumes static environment during `plan_path`. If obstacle moves during execution, `Replanner` (v2.5) handles it, but global path might become suboptimal.
